# ЖМЫХ-HUB

Единый хаб мемных сайтов про одногруппника Руслана. Это каталог всех сайтов проекта и фотогалерея в одном месте.

Проект статический: чистые HTML, CSS и JavaScript, без сборки, фреймворков и зависимостей. Из внешнего подключаются только шрифты Google Fonts.

## Что внутри

- **Сайты** — карточки с превью, описанием и кнопкой «Открыть». Сайты бывают двух типов: рабочие (`live`, открываются в новой вкладке) и локальные (`local`, лежат в этом же репозитории в папке `sites/`).
- **Галерея** — сетка фотографий. По клику фото открывается в полноэкранном просмотре с листанием, счётчиком и подписью. Подпись берётся из `alt` фотографии, а в сетке она показывается при наведении.

Выбранная вкладка запоминается, а ссылки `#sites` и `#gallery` открывают нужный раздел сразу.

## Запуск

Сайт можно открыть двойным кликом по `index.html`, но удобнее запустить небольшой локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу <http://localhost:8000>.

Локальные сайты подключены как git-сабмодули, поэтому клонировать проект нужно так:

```bash
git clone --recurse-submodules https://github.com/AbobaCorp/website-zhmyh-hab.git
```

Если репозиторий уже склонирован без сабмодулей:

```bash
git submodule update --init --recursive
```

```
├── favicon.ico
└── .gitmodules       # список сабмодулей
```

## Как добавить сайт

Всё редактируется в `js/config.js`, в массиве `SITES`. Скопируйте любой блок `{ ... }` и поменяйте значения:

| Поле      | Что означает                                                       |
| --------- | ------------------------------------------------------------------ |
| `title`   | название сайта                                                     |
| `desc`    | короткое описание                                                  |
| `url`     | ссылка (для локальных сайтов — путь вида `sites/<папка>/index.html`) |
| `type`    | `'live'` — рабочий сайт, `'local'` — сайт из этого репозитория     |
| `preview` | путь к скриншоту для карточки                                      |
| `emoji`   | смайлик-заглушка, пока нет скриншота                               |
| `label`   | подпись под смайликом                                              |
| `tint`    | цвет подсветки карточки в формате `'R, G, B'`                      |

Счётчик сайтов на главной обновляется автоматически.

**Превью.** Положите скриншот в `previews/` и укажите путь в `preview`. Если файла нет, то сначала пробуются другие расширения (`jpg`, `jpeg`, `png`, `webp`), а если не нашлось ни одного, показывается смайлик из `emoji`.

**Локальный сайт** подключается как сабмодуль:

```bash
git submodule add <адрес-репозитория> sites/<название-папки>
```

После этого добавьте его в `SITES` с `type: 'local'`.

## Как добавить фото

1. Положите картинку в папку `gallery/`.
2. Добавьте строку в массив `PHOTOS` в `js/config.js`:

```js
{ src: 'gallery/photo11.jpg', alt: 'Описание фото' },
```

Порядок в списке — это порядок в галерее. `alt` нужен не только для доступности: он же показывается как подпись к фото. Если оставить его пустым, подписи не будет.

Если список `PHOTOS` пуст, на странице появится подсказка и плитки-заглушки.

## Управление в просмотре фото

| Действие            | Телефон / планшет  | Компьютер                          |
| ------------------- | ------------------ | ---------------------------------- |
| Следующее / прошлое | свайп влево/вправо | кнопки ‹ ›, клавиши ← →, перетаскивание мышью |
| Первое / последнее  | —                  | клавиши Home / End                 |
| Закрыть             | крестик, тап по фону | крестик, клик по фону, Esc       |

Листание зациклено: после последнего фото снова идёт первое.
